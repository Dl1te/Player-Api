# Player-Api

API для управления игроками 

## Быстрый старт

```bash
# Клонировать
git clone https://github.com/Dlqte/ClansTracker.git
cd ClansTracker

# Установить зависимости
pip install -r requirements.txt

# Настроить .env
cp .env.example .env
# Отредактируйте .env с вашими данными

# Запустить
uvicorn main:app --reload
